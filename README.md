# Qais Hamdan — Portfolio

Personal portfolio website of **Qais Hamdan**, a Full Stack Web Developer (CIS graduate, 2026) based in Amman, Jordan.

🔗 **Live site:** https://qaishamdan.github.io/Qais-Portfolio/
💼 **LinkedIn:** https://www.linkedin.com/in/qais-hamdan-b13206377/

## Features
- Responsive design for phones, tablets, laptops and ultra-wide screens
- English / Arabic (RTL) switch
- Dark / light theme and 5 accent colors
- Project cards with filters and detail popups
- Certificates gallery (14 certificates) with PDF download
- CV preview and download
- Contact form (Formspree) and WhatsApp button
- Offline support (PWA / service worker)

## Projects shown on the site
- Online Course Platform — ASP.NET Core · EF Core · SQL Server
- Pharmacy Management & POS — PHP · MySQL · Chart.js
- Alternative Course Requests Portal — PHP · MySQL
- ATM Banking System — C# console app
- Leon & Kasper Templates — HTML5 · CSS3 · JavaScript
- Interactive JavaScript Apps — vanilla JS

## Built with
HTML5, CSS3, vanilla JavaScript (no frameworks), Font Awesome, Google Fonts.

## Project structure
```
index.html      page markup
style.css       styles
script.js       behavior (theme, language, popups, form)
i18n.js         Arabic translations
sw.js           service worker (offline cache)
manifest.json   PWA manifest
assets/         images, project screenshots, certificates
```
